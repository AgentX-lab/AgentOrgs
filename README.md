# AgentOrgs

**AgentOrgs is a Kubernetes-native organization and collaboration control plane for AI agents.**

AgentOrgs allows users to declaratively organize heterogeneous agents into flexible organizational structures and define how agents, teams, and humans collaborate across organizational boundaries.

It separates the organization layer from the execution layer. AgentOrgs manages organizational relationships and collaboration boundaries, while pluggable agent runtimes such as AgentTeams, OpenClaw, and Hermes remain responsible for executing agent workloads.
